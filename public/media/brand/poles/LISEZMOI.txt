Logos officiels des 3 pôles (fichiers fournis par le client, conservés tels quels) :
  eventia image&personal brading.png  -> logo complet EVENTIA IMAGE & PERSONAL BRANDING
  eventia hotesses.jpeg               -> logo complet EVENTIA HÔTESSES
  Eventia events.png                  -> logo complet EVENTIA EVENTS
  logo eventia hotesses.png           -> symbole seul Hôtesses (étoile blanche)
  logo eventia events.png             -> symbole seul Events (feuille bleue)

Le site affiche chaque pôle en logo transparent, comme le logo EVENTIA SARL (sans fond) :
  {pole}-symbole.png   -> symbole découpé dans les fichiers du client (ni redessiné ni recoloré)
  {pole}-wordmark.png  -> mot « Eventia » découpé dans le logo complet du pôle
  Le nom du pôle est écrit en texte (police Poppins), avec les proportions mesurées sur chaque logo d'origine :
    image    -> « IMAGE & PERSONAL / BRANDING », bleu royal #0069BC
    events   -> « EVENTS », bleu royal #0069BC
    hotesses -> « HÔTESSES », blanc (comme le logo officiel Hôtesses)
  Réglages (couleur, tailles, espacements) : app/Support/Media.php, constante POLE_LOCKUPS.
